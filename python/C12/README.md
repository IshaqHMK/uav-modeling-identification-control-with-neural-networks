# C12 Lightweight Replay of the C10 Model

Minimal evaluation script for the rad-based direct model from C10.

## Files
- `C12_quad_mlp_sdg_pqr_light.py`

## Method summary
- Loads the C10 checkpoint and experimental log.
- Runs a full-sequence replay.
- Plots angles and rates in degrees for quick inspection.

## Notes
- Inference only; no retraining.

## Outputs
- Plots with the `C12_light_` prefix.
