# C43 Shared GRU Training on Simulated Datasets

Trains the shared controller-imitation GRU on the clean fixed-step datasets generated by C42.

## Files
- `C43_pid_rnn_gru_error_to_control_train.py`

## Method summary
- Loads the `C43_sim_dataset_*.mat` files instead of experimental logs.
- Builds the same PID-feature sequences used in the earlier controller-imitation work.
- Trains and saves a shared GRU checkpoint for simulated-data testing.

## Notes
- This is the last controller-imitation milestone before the simplified linear Z-axis series starts at C45.

## Outputs
- Checkpoint: `models/C43_ep50_shared_pid_gru_SL_<sequence_length>.pt`.
