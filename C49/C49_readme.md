# C49 Linear Z-Axis PID + GRU (PRBS Wind Disturbance)

This version keeps the linear Z dynamics and replaces the **constant wind** disturbance with a **PRBS wind** signal. Training uses one fixed reference and three wind amplitudes (0/1/5 N).

## Files
- `C49_linear_z_pid_WFdBk.py` trains a GRU using `[z_meas, error, error_rate, error_integral]` with PRBS wind.
- `C49_linear_z_pid_WFdBk_tstTrained.py` loads the trained model and tests it using the same PRBS wind settings.

## What changed from C47/C48
- Wind disturbance is now PRBS instead of a constant step.
- Same reference profile is used across datasets; only wind amplitude changes.

## PRBS wind model
Wind is applied after `WIND_START_TIME` and generated by:
- `WIND_MODE = "prbs"`
- `WIND_SETTINGS["prbs"]["hold_steps"]`: duration of each PRBS bit
- `WIND_SETTINGS["prbs"]["width"]` and `taps`: LFSR length and taps
- `WIND_SETTINGS["prbs"]["seed"]`: sequence seed

The PRBS value is multiplied by the dataset wind amplitude from `WIND_FORCES`.

## Key configs
At the top of each script:
- `WIND_FORCES` sets the dataset wind amplitudes (0/1/5 N).
- `WIND_START_TIME` sets when wind begins.
- `WIND_MODE` / `WIND_SETTINGS` define PRBS behavior.
- `REFERENCE_PROFILE_ID` fixes the training reference.
